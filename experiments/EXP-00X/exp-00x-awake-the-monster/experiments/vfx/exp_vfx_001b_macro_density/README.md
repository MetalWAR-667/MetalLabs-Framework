# EXP-VFX-001b — Macro Density

**Status: Accepted / Historical experiment.** La máscara macro mejoró la
composición y permitió masas densas y regiones abiertas sin añadir detalle local.

Compara Dual Drift con una máscara adicional de densidad a gran escala. Estudia
composición espacial, no detalle local. La referencia sin máscara se obtiene
desactivando `Enable Macro Density`.
