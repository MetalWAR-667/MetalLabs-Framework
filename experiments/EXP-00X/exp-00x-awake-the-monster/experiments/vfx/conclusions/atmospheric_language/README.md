# Visual Lab — Atmospheric Language Closure

**Status:** Accepted  
**Scope:** Visual language research closure  
**Project application:** Awake the Monster

**Production update:** Atmospheric Layer is integrated. Memory Layer now uses
an original 18-node DreamGraph with fixed progression across Cards 01–06. The
external procedural-network reference remains research-only; no external shader
code is required by the production implementation. DreamGraph itself remains
an experimental integration pending final visual acceptance.

## 1. Purpose

This research block did not seek a collection of isolated effects. It examined
which visual vocabulary could sustain the narrative, give each effect a clear
responsibility and communicate changes in the dream without overwhelming the
central card.

Visual Lab does not exist to collect shaders. It exists to identify visual
languages and validate how they communicate narrative meaning.

## 3. Main findings

### Fog

Fog provides volume and defines the spatial atmosphere. It can sustain a
persistent background language and combines coherently with particles.

### Particles

Particles provide life and movement. Their behaviour communicates narrative
intention, while density, radius and speed alter perceived scale and urgency.
Fog and particles therefore form one coherent atmospheric family.

### Ink

Ink works as an isolated visual language, but does not combine cleanly with
persistent fog and particles. When all three compete, Ink tends to homogenize
the visual hierarchy.

It should be reserved for transitions, corruption, reveals, interface events or
other exceptional moments. It is not part of the persistent atmospheric layer.

### Layer stacking

Combining visually attractive effects does not automatically create a stronger
visual identity. Additional layers can reduce hierarchy and semantic clarity.
Every effect requires a distinct narrative responsibility.

## 4. Final visual language

The research defines two complementary systems. They are not simultaneous
layers by default and should not be collapsed into a single visual stack.

### Language A — Dream World

**Working name:** Atmospheric Layer

Represented by:

- smoke;
- fog;
- slow atmospheric movement;
- particles;
- geometric forms;
- depth;
- controlled noise.

It communicates the dream, unstable space, uncertainty, the physical or mental
environment and the world surrounding the player.

### Language B — Memory Network

**Working name:** Memory Layer

Represented by:

- nodes;
- connections;
- bifurcations;
- accumulated structures;
- changing connectivity;
- mathematical and psychedelic motion.

It communicates chained memories, branching recollections, the memory of the
world, neural reconstruction and the monster recovering consciousness.

The procedural network is currently a validated conceptual direction, not a
final production technology.

## 5. Narrative progression

The two languages may alternate through fades:

```text
Atmospheric Layer
        ↓
       fade
        ↓
brief Memory Layer appearance
        ↓
    fade back
        ↓
Atmospheric Layer
```

As cards or chapters advance:

- the Memory Layer appears more often;
- connections become denser;
- nodes persist longer;
- the network gains depth;
- transitions become slower;
- the network becomes increasingly difficult to hide;
- eventually, the Memory Layer may replace the Atmospheric Layer.

The accepted prototyping hypothesis is that the player believes they are
escaping the nightmare, while their progress is rebuilding the memory and
consciousness of the monster.

The final connection may represent the completion of the memory structure, the
awakening of the monster and the end of the nightmare. This is a narrative
hypothesis for prototyping, not a definitive script.

## 6. Narrative parameters

| Parameter | Narrative meaning |
|---|---|
| Density | Quantity of recovered memories |
| Speed | Proximity or urgency of awakening |
| Persistence | Memories becoming permanent |
| Color | Mental or narrative state |
| Depth | Age or layer of memories |
| Noise | Corruption, false memory or unstable recall |
| Connection distance | Capacity of memories to recognize and connect with each other |

These parameters are not merely technical controls. They are art-direction
controls and should be adjusted according to narrative intention.

## 7. Ink policy

Ink is not deprecated.

Ink is not part of the persistent atmospheric composition.

Ink remains available as a separate event language for:

- transitions;
- corruption;
- reveals;
- special cards;
- interface disturbances;
- narrative ruptures.

Its value comes from contrast with the persistent language. Constant use would
reduce that distinction.

## 8. Scope closure

No more atmospheric shaders are required for the current scope. The shader
research block is closed.

Future work should focus on implementation, integration and narrative
validation. A new effect requires a concrete narrative need; visual novelty
alone is not sufficient justification for reopening this block.

> A new shader is not a feature unless it communicates something the existing
> visual languages cannot express.

## 9. Licensing and provenance note

An external shader was used as visual inspiration and research reference for
the procedural network. Its provenance and licensing must remain documented.

No external code should be included in a distributed build without explicit,
compatible permission. Any original implementation should be designed from the
project's own functional and narrative specification.

Visual inspiration and code provenance are separate matters.

**External reference status:** Research only / permission pending
