# EXP-VFX-001 — Dual Drift

**Status: Accepted / Historical experiment.** Texture sobre textura produjo la
base de niebla orgánica más convincente.

## Intended hypothesis

Two independently moving visual fields can produce organic atmospheric depth without requiring complex simulation.

## Closure

Implemented and accepted as the foundation of the fog language. Later
experiments extended its composition without invalidating this result.
