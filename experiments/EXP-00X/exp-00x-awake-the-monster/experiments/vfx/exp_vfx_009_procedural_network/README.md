# EXP-VFX-009 — Procedural Network

**Status: Accepted as visual language / Historical experiment.** La red ofreció
patrones fértiles. La build usa después un DreamGraph original y más contenido,
no el código ni la tecnología del experimento.

## Pregunta

¿Qué lenguaje visual produce una red procedural de nodos móviles y conexiones?

## Hipótesis previa

Podría sugerir tejido onírico, red neuronal, constelación, estructura matemática,
sistema arcano, información viva o espacio digital. Son hipótesis, no resultados.

## Procedencia

El shader fue proporcionado como material experimental. Su autoría y licencia no
están confirmadas y deberán verificarse antes de cualquier distribución.

## Parámetros

Se exponen movimiento de nodos y profundidad; grosor, distancia e intensidad de
red; escala e intensidad de composición; color y variación cromática. Cada uno
produce una diferencia perceptiva directa.

## Presets

Original, Constellation, Neural, Dream Lattice y Unstable. Sus nombres describen
la intención previa de configuración, no una lectura validada.

## Riesgos técnicos

- Coste por píxel elevado por cinco capas y bucles internos.
- Singularidad potencial del brillo, limitada mediante una distancia mínima.
- Posibles conexiones degeneradas, protegidas con denominador mínimo.
- Dependencia de resolución mediante `SCREEN_PIXEL_SIZE`.
