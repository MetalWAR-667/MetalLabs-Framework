# EXP-VFX-008 — Visual Hierarchy

## Pregunta

¿Cuántas capas visuales simultáneas puede procesar el ojo antes de que el espacio
deje de ser legible?

## Hipótesis

Una atmósfera eficaz necesita una jerarquía clara: no todos los sistemas pueden
tener el mismo peso visual.

## Escenarios

- Solo Fog
- Solo Particles
- Solo Ink
- Fog + Particles
- Fog + Ink
- Ink + Particles
- Los tres simultáneamente
