# EXP-VFX-004 — Geometric Flow Fields

**Status: Accepted and Integrated.** Su campo geométrico es la base conceptual
de la niebla de producción. El experimento original permanece aislado.

Aplica campos geométricos invisibles a las coordenadas de muestreo de las tres
capas atmosféricas. La niebla sigue siendo el único material visible.

Incluye Vortex, Ring y Arc, además de una visualización de depuración opcional.
