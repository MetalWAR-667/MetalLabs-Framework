# EXP-VFX-002 — Presence Oscillation

**Status: Accepted / Historical experiment.** La oscilación lenta se conservó
como aprendizaje temporal, no como sistema narrativo independiente.

Estudia si cuatro oscilaciones sinusoidales, lentas e independientes, pueden hacer
que la atmósfera parezca respirar sin que el movimiento resulte identificable.

Reutiliza Macro Density y no añade capas visuales, texturas ni shaders.
