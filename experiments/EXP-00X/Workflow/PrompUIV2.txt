Design a complete empty card template for a narrative horror adventure game.

The card must not resemble a collectible trading card.

Instead, it should feel like a beautifully preserved page carefully removed from an ancient illustrated book documenting impossible dreams.

If every gameplay element were removed and the page were printed in a nineteenth-century book, it should still be perceived as a beautiful editorial illustration rather than a game component.

The page should feel timeless, elegant, restrained and highly readable.

The composition must be vertical, spacious and carefully balanced.

Large empty editorial areas must remain available for text and gameplay elements that will be added later inside the game engine.

Do NOT include:

• text
• typography
• numbers
• icons
• UI elements
• buttons
• symbols
• game mechanics

---

Illustration

The upper half of the page contains a large engraved illustration framed by an elegant border.

The lower half contains large empty parchment sections separated by subtle engraved dividers.

The page layout should resemble a classical illustrated novel rather than a modern card game.

---

Materials

Aged parchment.

Fine engraved borders.

Victorian book ornamentation.

Subtle decorative geometry.

Old paper textures.

Minimal editorial embellishment.

Everything should prioritize readability.

Architecture

Impossible monumental architecture.

Ancient stone.

Massive gates.

Floating structures.

Infinite stairways.

Silent ruins.

Mathematical spatial logic inspired by Escher without becoming surreal abstraction.

The architecture should always feel physically believable while logically impossible.

---

Atmosphere

Dreamlike.

Silent.

Ancient.

Lonely.

Sacred.

Melancholic.

Vast.

The world should feel governed by unknown mathematical laws.

---

Color Philosophy

The illustration is predominantly monochrome.

The parchment, engraving and architecture remain almost entirely black, sepia and grey.

Color is used only as a narrative accent.

Never paint the whole illustration.

Instead, selectively illuminate a single meaningful architectural element.

Examples:

• a distant doorway
• an impossible portal
• a staircase disappearing into light
• a mysterious window
• a forgotten monument

The color should softly glow without becoming magical fantasy.

It should feel symbolic rather than decorative.

The surrounding illustration remains monochrome.

Golden Rule

Design an illustrated book page first.

The game will be built on top of it later.

The illustration should invite contemplation before interaction.

The page should look as if it belonged to a forgotten journal describing places that should not exist.
