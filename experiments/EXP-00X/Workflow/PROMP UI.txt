Design a complete empty card template for a narrative horror card game.

The card should NOT look like a collectible trading card.

Instead, it should resemble a beautifully illustrated page carefully removed from an ancient illustrated book.

The overall feeling should evoke a nineteenth-century fantasy engraving, classical adventure books, and antique editorial illustration.

The card must feel elegant, restrained and timeless.

The composition should be clean, spacious and highly readable.

Leave generous empty areas intended to later contain dynamic text added inside the game engine.

Do NOT include any text, typography, icons, symbols, numbers, UI elements or game mechanics.

The illustration area should occupy roughly the upper half of the page, framed by a refined engraved border.

Below it, create large empty editorial areas separated by subtle engraved dividers, designed to hold narrative text and gameplay information later.

Use aged parchment, engraved ornaments, subtle geometric motifs and delicate decorative borders inspired by old scientific manuscripts and impossible architecture.

The decoration should never overpower the composition.

Everything must support readability.

The page should feel like it belongs to a forgotten illustrated journal documenting impossible dreams.

Influences:

• Gustave Doré
• Arthur Rackham
• M. C. Escher (architectural language only)
• Victorian book illustration
• Antique scientific manuscripts
• Lord Dunsany

Visual style:

• Black and white engraved illustration
• Slight sepia aged paper
• Fine crosshatching
• Elegant editorial layout
• Minimal ornamentation
• Large breathing margins
• Strong vertical composition
• Highly printable
• Premium book page aesthetic

Golden Rule:

If every gameplay element were removed, the result should still look like a beautiful illustrated page from an antique book rather than a game card.
Design the page first. The game will be built on top of it later.
