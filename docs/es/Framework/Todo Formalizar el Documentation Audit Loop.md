TODO — Formalizar el Documentation Audit Loop
Objetivo

Convertir el ciclo de auditoría documental en una práctica estándar del MetalLabs Framework.

Motivación

Durante Lands of Folklore se ha comprobado que una implementación validada no garantiza por sí sola que el conocimiento del proyecto permanezca coherente.

La auditoría posterior permite confirmar que:

la arquitectura sigue siendo válida;
HEAD continúa respetando el diseño;
la documentación refleja el estado real del proyecto;
las decisiones importantes quedan consolidadas antes de iniciar el siguiente sprint.

Siguiente Sprint
Objetivos del Documentation Audit
Auditar concepto ↔ implementación.
Auditar documentación ↔ HEAD.
Detectar deuda técnica menor.
Consolidar decisiones arquitectónicas.
Evitar que el conocimiento del proyecto se degrade con el tiempo.
Resultado esperado

Cada sprint termina respondiendo tres preguntas:

¿Funciona?
¿Sigue siendo coherente?
¿Qué conocimiento queda consolidado para el futuro?
